## Testing

Run the test suite to verify all API endpoints:

```bash
pytest
```

Run tests with verbose output to see individual test results:

```bash
pytest -v
```

View code coverage report:

```bash
pytest --cov=src
```

Tests are located in the `tests/` directory and cover all API endpoints:
- Root endpoint redirect
- Activities list retrieval
- Participant signup flow
- Participant removal flow
